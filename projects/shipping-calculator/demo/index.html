Shipping Cost Calculator

This project calculates parcel delivery costs based on factors such as weight, distance, parcel size, insurance, and delivery type. This project uses object-oriented programming concepts like inheritance, method overriding, and class specialization to apply different priocing rules for standard, express, and international shipments.
